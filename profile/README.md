## Open source

| Project | What it does |
|---|---|
| **[overhang](https://github.com/flowful-ai/overhang)** | Enclosures and brackets designed by chat. Print-ready STL or 3MF in under a minute, self-hosted. |
| **[cad-skill](https://github.com/flowful-ai/cad-skill)** | A Claude Code skill that turns a description into a parametric, 3D-printable CadQuery model, with STL export and previews. |
| **[tasksflow](https://github.com/flowful-ai/tasksflow)** | Task management with an MCP server, so your AI agent works the same board you do. GitHub and Slack integrations, Bun. |

Issues and pull requests are welcome on all of them.

## What we build

- **AI agents**: chat and voice assistants grounded in a company's own docs, a helpdesk ([TicketFlow](https://flowful.ai/packages/ticketflow/)), email automation.
- **Custom software**: web apps, internal tools, APIs and MCP servers, with or without AI inside.
- **Hosting**: apps and data in the EU, or on the client's own infrastructure.

Most client work is private. The [case studies](https://flowful.ai/projects/) show what it looks like in practice.
